# 🌫️ Air Quality Monitor using ESP32 (IoT + Blynk)

⭐ Star this repo if you find it useful!

An **IoT-based Air Quality Monitoring System** built using **ESP32**, capable of monitoring air pollution, temperature, and humidity in real time. The system displays data on an **OLED screen**, sends it to the **Blynk mobile app**, and automatically **controls a ventilation fan and alerts users** when air quality becomes unsafe.

---

## 🚀 Why This Project?

Indoor air pollution is often ignored but can seriously impact health. This project provides a **smart, low-cost, and automated solution** to monitor and improve indoor air quality using modern IoT tools.

Perfect for:
- Students
- IoT / Embedded learners
- Smart home enthusiasts
- Mini / major projects

---

## ✨ Key Features

✅ Real-time air quality monitoring (MQ135)  
✅ Temperature & humidity sensing (DHT11/DHT22)  
✅ Live OLED display (SSD1306)  
✅ Remote monitoring via **Blynk IoT App**  
✅ Automatic fan control using relay  
✅ Buzzer + mobile notification alerts  
✅ WiFi-enabled & fully automated  
✅ Beginner-friendly yet practical  

---

## 🧠 System Functionality

- Continuously monitors air quality levels  
- Classifies air as **Good / Moderate / Poor / Hazardous**  
- Automatically turns **ON a fan** when pollution rises  
- Triggers **buzzer and Blynk notifications** in unsafe conditions  
- Displays live data locally and remotely  

---

## 🧩 Hardware Used

- ESP32 Development Board  
- MQ135 Air Quality Sensor  
- DHT11 / DHT22 Temperature & Humidity Sensor  
- 0.96" OLED Display (SSD1306, I2C)  
- Relay Module  
- Fan (AC/DC)  
- Buzzer  
- Jumper wires & power supply  

---

## 📱 Blynk Dashboard

The Blynk mobile app shows:
- 🌫️ Air Quality Level (PPM)  
- 🌡️ Temperature (°C)  
- 💧 Humidity (%)  
- 📊 Air Quality Status  

Push notifications are sent automatically when air quality degrades.

## ⚠️ Limitations

- MQ135 provides **approximate values** without calibration  
- Requires WiFi for remote monitoring  
- Not intended for industrial-grade air analysis
